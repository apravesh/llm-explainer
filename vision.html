Pack, don’t pad.

Pixtral packs image sequences together. A block-diagonal mask keeps attention inside each image; the language decoder combines them later.

A note on resolution. Flexible does not mean unlimited. Bigger images produce more patches, and dense encoder attention scales quadratically with the patch count. The demo uses small images to keep every number inspectable.

UNDER THE HOOD

Real dimensions.
Untrained weights.

The browser executes a dense, full-width vision encoder with deterministic synthetic weights. No pretrained weights, semantics, class predictions, or language generation.

  • Pixtral: 1,024 hidden features, 16 heads × 64, 4,096-wide gated MLP, all 24 blocks. Projector: 1,024 → 5,120 → 5,120.
  • ViT-B/16: 768 hidden features, 12 heads × 64, 3,072-wide GELU MLP, all 12 blocks, and a CLS readout.
  • Native 16 × 16 RGB patches. Images are deliberately resized to a small demo resolution (up to 128 pixels on the longer side for Pixtral, 96 × 96 for ViT) so token count remains manageable.
  • WebGPU when available; WebAssembly SIMD or JavaScript fallback inside a Web Worker. Every preceding layer is computed. Changing inspected blocks reuses cached activations.
  • Seeded weights are regenerated on demand, not downloaded. Biases are omitted; normalization has identity gain / zero bias. RGB normalization and seeded weight initialization are illustrative, not pretrained inference preprocessing.

Dense canvas overviews pool activation values when several features share a screen pixel. Large weight overviews are explicitly sampled. Exact feature windows and numerical input/output indices reach every element. A dot product always includes every input, not just the displayed values.

Engine tensors use Float32. Numeric inspection accumulates the same dot product in Float64, so the UI reports small rounding differences rather than claiming bitwise equality. Colors do not indicate learned semantic roles.

The projector is computed. The causal text decoder and classifier handoffs are schematic and are not executed. The separate 4D RoPE lab uses two fully visible feature pairs and teaching angular speeds; the real encoder heads use 64 features and their own frequency schedule.

Images stay on your device. No model downloads, accounts, analytics, or inference API. Full-dimensional computation may take several seconds; progress, cancellation, and CPU retry are available.
