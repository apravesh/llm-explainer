A pretrained model continues any text. Supervised fine-tuning (SFT) keeps training it on example conversations, so that the natural continuation of a question becomes a helpful answer.

01 / CHAT TOKENS

A chat is flattened
into one line of tokens.

The model never sees chat bubbles. A chat template writes the whole conversation as one string, with special tokens marking where each message starts and ends. That string becomes token IDs, exactly like any other text. [1]

Are these the same tokens in every model?

No. For example, Mistral-7B-Instruct-v0.1 wraps user messages with [INST] and [/INST]; the template above is intentionally fictional, with fictional IDs. Words and punctuation are kept whole for readability. Special tokens have reserved IDs and learned embeddings, not magical “instruction” behavior: the model learns their use from training examples. Some templates use role-specific tokens; others surround ordinary role names with special delimiters. Models may distinguish end-of-message, end-of-turn and end-of-sequence. Use the tokenizer and chat template matching the checkpoint, including its generation prefix. A system message, when supported, is serialized too. Avoid adding duplicate beginning/end tokens. Introducing new special tokens requires matching embedding/output entries and training—not just typing their spelling. Boundaries also are not a security barrier against prompt injection. [1]

02 / DEMONSTRATIONS, NOT JUST DOCUMENTS

Show the model
what a good answer looks like.

Pretraining data is any text. Instruct data is pairs: a request, and the response you wish the model gave. People write them, existing datasets are adapted, or a model drafts answers that get checked. A few good examples teach more than many sloppy ones. [2] [3]

From candidate answers to a training setFour hand-authored illustrations · no data collected

What does a stored record look like?
{"messages": [
  {"role": "user", "content": "Say hello."},
  {"role": "assistant", "content": "Hello!"}
]}

These are structured messages, not the final model input. The training pipeline applies the chat template, tokenizes, and marks which target tokens receive loss. At scale, use task/source diversity, annotation guidelines, privacy checks and held-out evaluations. Synthetic answers can carry the teacher’s errors and biases; review and filtering help but do not guarantee correctness.

03 / SAME NEXT-TOKEN OBJECTIVE

Read the question.
Get graded on the answer.

Fine-tuning is the same guess-the-next-token game as pretraining. The usual difference is which guesses are graded: the model reads the whole conversation, but only its predictions of the assistant’s reply count toward the loss. That choice is called a loss mask. Assistant-only loss is a choice, not the definition of SFT. [4]

One loss for the batch

L = Σ mₜ · [−ln p(xₜ | x<ₜ)] / Σ mₜ

mₜ = 1 for a graded target, 0 otherwise. Divide by graded tokens, not all tokens. Losses under different masks are not directly comparable quality scores.

Does masking the prompt stop gradients through it?

No. Its own next-token targets can be unscored, while assistant predictions still depend on prompt representations through attention. Gradients from those predictions can flow through the prompt-side computation to shared weights. A loss mask is not an attention mask: both modes still use causal attention.

For each vocabulary logit zⱼ, ∂L/∂zⱼ = mₜ · (pⱼ − 1[j = target]) / N, where N is the number of scored tokens. The displayed probabilities are an illustrative normalized distribution, not model output. The slider changes one target probability and redistributes the remainder equally among other vocabulary entries. We compute loss and this derivative, but do not simulate a weight update. The same two toy chats are used in both modes to isolate the mask; real pretraining data is usually broad text, not this chat dataset.

What stays the same?

The transformer, next-token cross-entropy, backpropagation and the optimizer. Training feeds in the correct previous answer tokens, not the model’s own samples.

What changes?

Start from pretrained weights instead of random ones. Use curated demonstrations. Pick a loss mask. Usually far less data and a smaller learning rate; sometimes only small adapters are trained.

What SFT is not

There is no reward and no trial and error: the model imitates the given answers. It does not guarantee truthfulness, safety or perfect instruction-following.
