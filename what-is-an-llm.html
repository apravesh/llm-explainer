INTRO / 01 · THE BIG PICTURE

How does an LLM actually work?

Reduced to its simplest form, a large language model is a black box with one job: read some text, guess what comes next. Everything else on this site builds on that.

ON THIS PAGEOne guessRepeatStoriesChat

01 / THE SIMPLEST FORM

Given a stream of words, predict the next word

What is an LLM in its simplest form? Text goes in, a guess for the next word comes out. That is the whole machine. Treat it as a black box for now; later chapters open it.

A token is the unit the model really guesses: usually a word, sometimes a piece of one. This page says “word”.

02 / REPEAT

Keep predicting the next word iteratively to produce full sentences and more

Add its guess to the end of the text and ask again. Each round gives one more word, so a sentence appears one word at a time, with no plan behind it.

the chosen word joins the text, and the longer text goes back in

03 / COMPLETION

Give the LLM the start of a story and ask it to complete it.

Keep the loop running and it continues any text. This was the first way LLMs were shown off: GPT-2 in 2019, then GPT-3 and PaLM, were given an opening and wrote what came next.

04 / CHAT

A chatbot is the same loop,
started with a script.

Write the conversation as text: User:, the question, a new line, then Assistant:. If the box has seen enough text shaped like this, the likeliest continuation is a reply.

What is inside this page’s box?
Not a real LLM. The box on this page looks up what followed the same words in about thirty hand-written example texts (three short stories, some simple sentences and seven chat exchanges) and turns the counts into percentages, trusting longer matches more than short ones. That is enough to show the behaviour honestly: a guess for the next word, repeated. It cannot answer a question it has not seen.
A real LLM replaces the lookup with a neural network holding billions of learned numbers, so it can continue text it has never seen before. Real chat models also use special marker tokens instead of the plain words “User:” and “Assistant:”; the Instruct chapter shows them.
