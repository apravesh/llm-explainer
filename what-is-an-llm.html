INTRO / 01 · THE BIG PICTURE

How does an LLM actually work?

Reduced to its simplest form, a large language model is a black box with one job: read some text, guess what comes next. This page shows that one job, what people use it for today, and how a chatbot answers with web search.

01 / THE SIMPLEST FORM

Given a stream of words, predict the next word

What is an LLM in its simplest form? Text goes in, a guess for the next word comes out. Add that word to the end of the text and ask again. Repeat, and full sentences and more appear one word at a time, with no plan behind them. Treat the LLM as a black box for now; later chapters open it.

the chosen word joins the text, and the longer text goes back in

A token is the unit the model really guesses: usually a word, sometimes a piece of one. This page says “word”; Tokens shows the difference.

02 / USE CASES

Same box.
A different beginning each time.

Four uses cover most of what people do with LLMs today. The model only ever continues text. What changes is the text it is handed, and what the app around it does with the words that come back.

This page’s toy box · not a real LLM

Give the LLM the start of a story and ask it to complete it. This was the first way LLMs were shown off: GPT-2 in 2019, then GPT-3 and PaLM, were given an opening and wrote what came next.

A chatbot is the same loop, started with a script. The app writes the conversation as text: User:, the question, a new line, then Assistant:. If the box has seen enough text shaped like this, the likeliest continuation is a reply.

What else are LLMs used for?
Summarising long documents, translating, pulling structured facts out of messy text, tutoring, customer support, and searching through a company’s own files. They all follow the same recipe: put the right text in front of the model, and let it continue.



03 / CHAT WITH WEB SEARCH
It cannot know today’s news.
So let it read first.
A model only knows what was in the text it was trained on, and training ended months or years ago. Ask about yesterday and it has nothing to go on. Chatbots with web search fix this without changing the model at all: the app runs a search on a search engine such as Google, and pastes what it finds into the text before the model answers. This is called retrieval-augmented generation, or RAG.

The town, the race and the websites are invented for this example, so nothing here can be mistaken for real news.


The model learned nothing new
Its weights are unchanged. The facts were sitting in the prompt, and it wrote an answer from them. Ask again tomorrow without search and it is back to not knowing.
The answer is only as good as the results
If the search returns the wrong pages, or pages that are wrong, the model will usually repeat them. Showing sources lets you check.
The same trick works on your own files
Swap the web search for a search over a company’s documents and you have the usual “chat with your data” product. Search first, paste, then answer.


What is simplified here?
Real chatbots decide for themselves whether a question needs a search, may run several searches, and often open and read whole pages instead of short snippets. The search request and the results travel in special message formats rather than as plain “Search results:” text, and long pages are cut into pieces so only the most relevant parts are pasted in. The idea is unchanged: fetch text, put it in the prompt, let the model continue. The model can still misread a source or state something the results do not say, so citations are a help, not a guarantee.



What is inside this page’s box?
Not a real LLM. The box in the next-word, creative writing and chat demos looks up what followed the same words in about thirty hand-written example texts (three short stories, some simple sentences and seven chat exchanges) and turns the counts into percentages, trusting longer matches more than short ones. That is enough to show the behaviour honestly: a guess for the next word, repeated. It cannot answer a question it has not seen. The code, agent and web search examples are hand-written illustrations, not model output.
A real LLM replaces the lookup with a neural network holding billions of learned numbers, so it can continue text it has never seen before. Real chat models also use special marker tokens instead of the plain words “User:” and “Assistant:”; the Instruct chapter shows them.
