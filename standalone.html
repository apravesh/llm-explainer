Pack, don’t pad.

Pixtral packs image sequences together. A block-diagonal mask keeps attention inside each image; the language decoder combines them later.

A note on resolution. Flexible does not mean unlimited. Bigger images produce more patches, and dense encoder attention scales quadratically with the patch count. The demo uses small images to keep every number inspectable.

UNDER THE HOOD

Real calculations.
A teaching-sized model.

This explorer runs a deterministic, untrained transformer entirely in your browser. Its visualizations are computed from the displayed image—not canned attention maps.

  • Actual RGB patchification and linear projection.
  • 4 blocks, 3 attention heads, 24 hidden dimensions, 8 dimensions per head, and a 48-wide FFN.
  • ViT path: input position vectors, a [CLS] token, layer normalization, and GELU MLPs.
  • Pixtral path: aspect-preserving resize with edge padding, RMS normalization, per-layer 2D RoPE, a gated FFN, and a two-layer teaching projector (24 → 32 → 32).

What this is not: pretrained ViT or Pixtral inference. All weights, including position embeddings and [CLS], are seeded random parameters. Heads do not have learned semantic roles. There are no classification predictions or language generation. The “What next?” stage shows actual encoder/projector vectors and a symbolic decoder handoff—not a running text model.

The attention-stage decoder-mask switch is a comparison for all heads in the inspected block, using the encoder’s Q/K/V. The concatenation and output projection show comparison values, but the actual encoder run and later blocks remain unchanged. The value-mixing animation computes partial sums and returns the exact head output; it is not a learned explanation of the image.

The RoPE lab isolates the position mechanism with fixed vectors and an adjustable frequency scale; its score is not the full encoder attention score. It uses the Pixtral paper’s alternating row/column pair convention.

Images stay on your device. Sample illustrations are original SVG artwork included with this demo. No accounts, APIs, analytics, or model downloads.
